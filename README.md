# Portfólio — Amanda Duaibs

Portfólio pessoal de análise de dados e BI, com identidade visual inspirada em Van Gogh (azuis profundos e dourado).

## Sobre

Site single-page com 4 projetos de análise de dados e BI, cada um com página interna de detalhes, artigos no Medium e contato.

## Projetos

- **Análise de Vendas entre Filiais** — Power BI
- **Análise de Vendas Internas — Gatito PetShop** — Power BI (com vídeo de demonstração)
- **Análise de Performance de Campanha — Tráfego e Aquisição** — Looker Studio (dashboard interativo incorporado)
- **Análise de Logística — Hermex Logística** — Looker Studio (dashboard interativo incorporado)

## Tecnologias

- HTML5, CSS3, JavaScript (site single-page)
- SQL, Python, Power BI, Looker Studio, DAX, ETL

## Como visualizar

Abra o arquivo `index.html` em qualquer navegador, ou acesse a versão publicada via GitHub Pages.
